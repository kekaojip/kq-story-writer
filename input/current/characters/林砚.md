# 林砚｜第001章可用人物信息

- 年龄：24岁。
- 当前身份：城市物业外包维修员。
- 核心特质：冷静、验证欲强、风险意识高。
- 当前目标：处理眼前故障，把被困住户安全带出。
- 人物弱点：容易因为相信“证据足够就能控制风险”，主动把自己置于验证条件里。
- 说话方式：短、直接，不爱解释自己为什么聪明；先做验证，证据链可以在结果出现后再说明。

## 本章知识边界
- 开场时，他把这件事当作异常但仍可能存在普通解释的电梯故障。
- 他不知道异常体系的名称和来源。
- 他不知道自己存在可主动使用的“修补”权限。
- 只有当多套证据出现无法兼容的冲突后，他才首次看见异常视觉。

## 表达提醒
可靠感来自选择和验证，不来自旁白宣布“他很冷静”“他已经看穿”。
