# 林砚｜第1章 Writer Slice

- 19岁，青衡宗外门籍录房弟子，凡俗出身。
- 当前修为：炼气二层末段。
- 当前身份处境：地位低，但因为工作能接触名册、任务回执、矿役调令等基层制度信息。
- 核心特质：克制、算得清、敢下注、记人情但不滥好心。
- 行为习惯：遇事先看规则、价格、期限和真正有决定权的人；不先喊口号。
- 语言：短、实际。面对压力先确认事实。
- 当前资源：3枚下品灵石、4点宗门贡献。
- 当前家庭锚点：妹妹林小满每月需约0.5枚下品灵石等值药钱；不用展开长回忆。
- 当前不知道：问果、名单幕后者、任何未来真相。
- 本章不可提前拥有：炼气四层能力，直到章末选择结果后才成立。
- 主角代理权：名单核对、常规路线判断、未来结果比较和最终选择都必须由林砚本人完成。
