# 上一章正文尾巴

电梯开始上行。轿厢里安静下来，只听得见曳引机的声音从井道深处传上来。显示屏上的数字跳了一下：五，然后直接是七。中间没有六。

林砚扶着扶手，电梯跑得很稳，钢丝绳的震动均匀，机械上没听出哪里有毛病。

"它怎么上来了？"老周问。

林砚没答。轿厢在七楼停住，门没开，停了两秒，又开始往下走。

老周扶着轿壁，声音发紧："它、它又下去了？"

"嗯。"林砚抬头盯着显示屏，"看着它。"

数字跳了一下：五。

没有六。从七到五，屏幕上始终没出现过六这个数字。

然后喇叭响了。轿厢顶部那个老式扬声器先嘶过一声电流杂音，接着一个女声慢慢地往外念：

"六楼到了。"

老周的喘气声一下子没了。

"六楼？"老周的声音干哑，"它到的哪门子六楼？"

显示屏上明明白白是"5"，喇叭里却念着"六楼到了"。林砚低头看了一眼操纵盘，六楼的按键没有亮，安安静静地待在那排按钮中间。他的拇指悬在急停键上方，没有按下去。喇叭里的电流声滋滋地响着，没有再念第二遍。

电梯停了。

轿门自己开始往两边退，很慢，像有人在门后面一寸一寸地推。

门缝里渗进来的，是黑的。五楼走廊那盏声控灯，没有亮。

老周往后退了一步，后背撞上轿壁，声音卡在喉咙里："这，这不是五楼吧？"

林砚没答。

门还在开。
