# 青衡宗矿役与修炼刻度｜第1章规则切片

## 修为
- 林砚开篇：炼气二层末段。
- 炼气共九层。
- 炼气四层：青衡宗外门明确的免强制基础矿役资格线。
- 本章未来分支里林砚可以真实修到炼气四层；现实里只有章末带回结果后才成为四层。

## 矿役
- 黑石矿是青衡宗下属低阶灵矿。
- 基础矿役月例约5枚下品灵石，高于普通外门岗位，但矿毒、坍塌、地底妖虫导致长期损耗与事故风险明显更高。
- 矿役调令先公示3日，再正式生效。
- 炼气四层及以上外门弟子不得被强制派入基础矿役。
- 本章林砚名字已在调令上，但尚处公示期；不得提前撤名。

## 资源尺子
- 普通外门基础月例：2枚下品灵石。
- 籍录房稳定杂务补贴：每月另1枚。
- 林砚开局持有：3枚下品灵石、4点宗门贡献。
- 妹妹林小满一月药钱折算约0.5枚下品灵石。

## 籍录房
- 负责外门名册、任务回执、岗位调令、贡献记录等基层事务。
- 林砚熟悉正常轮转顺位和公示日期，所以能发现自己的名字至少提前了一个批次。
- 本章只能确认“顺位异常”，不能确认是谁动了名单、为什么动。
