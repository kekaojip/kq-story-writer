# 问果｜第1章规则切片

## 本章允许 Writer 知道并使用
1. 问果让林砚从当前现实状态进入一条真实未来分支。
2. 当前初始命数为1，炼气期单次未来跨度最多90日。
3. 推演结束后，只能从该分支里真正已经达成的结果中带回一个。
4. 一个结果必须是单一完成态，不能把多个收益打包成一句。
5. 本章结算可出现：炼气四层、少量未来所得灵石、与矿区有关但不完整的单项信息等已实际达成候选；最终林砚必须选炼气四层。
6. 带回结果本身完整成立，不附赠根基暗伤、随机反噬或隐藏惩罚。

## 本章不得解释
- 问果真实来源。
- 可能世界是否真实存在。
- 后续“持有/名位/因果/界域”权限层。
- 命数后续完整获取机制，除非当前提示仅说明初始命数为1。
- 任何司命相关内容。

## 表达边界
- 问果不人格化，不和林砚斗嘴。
- 提示短，只承担必要规则和结算。
- 推演不是系统流水账：允许展开矿役、修炼到四层、死亡三个与选择直接有关的关键节点，其余时间可自然压缩。
- 问果不给推荐答案，结果价值比较必须由林砚自己完成。
