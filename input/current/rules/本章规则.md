# 第002章规则切片

## 当前世界层规则

- 夜间电梯“必须在六楼停一次”的住户经验仍只是经验，不等于已证实真理。
- 同一事件可能被不同信息层记录成互不兼容的现实。
- 林砚目前只能看见冲突，不能直接修改规则。
- 验证必须来自可重复、可对照的现实记录，不靠直觉宣布答案。

## 本章允许得到的结论

- 显示器故障不能单独解释全部异常。
- 机械行程、门磁、监控、播报可能在记录不同层面的现实。
- 红色互斥标记会随着验证增加而更清晰。

## 本章禁止得到的结论

- 哪条规则最终为真。
- 六楼的真实本质。
- 红线或补丁能力的来源。
- 组织体系或更高层规则结构。

## 本章结尾只允许出现

`冲突已确认：可申请临时修补`

以及：

`错误修补将产生回滚债。`

不得继续实际执行修补。
