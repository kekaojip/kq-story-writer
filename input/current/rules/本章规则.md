# 第001章可用世界规则

## 已允许写入正文
- 城北旧居民楼的住户长期流传并实际遵循一条夜间安全经验：凌晨后乘电梯下行，要在六楼停一次；如果没有停，不要在一楼出去。
- 这条经验在居民认知里已经持续多年，但本章不解释它为何有效。
- 今晚出现三套互相冲突的信息：住户体感、监控记录、机械运行数据。
- 林砚的异常视觉只在“同一现实中出现无法同时成立的状态”时首次显现。

## 本章不能当成已知事实
- 六楼究竟存在还是不存在。
- 哪一套记录代表真正现实。
- 夜间安全经验的来源。
- 异常视觉的机制、名称和上限。
- 世界是否存在统一的规则维护体系。

写作时允许角色提出猜测，但猜测不能由叙述者盖章成真相。
