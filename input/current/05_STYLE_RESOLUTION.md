# STYLE RESOLUTION

## ACTIVE
- base_language: 自然现代汉语；普通顺口优先于文学化加工；题材词可以专业，普通句子不要自动做旧、公文化、论文式抽象化或生造搭配。
- POV / narrator_distance: 第三人称限知，只贴林砚；不直接透视配角心理。
- sentence_rhythm: 短中句为主，关键判断可更短；不追求句句有力，不连续做漂亮闭合。
- paragraphing: 移动端友好，但同一注意对象、同一局部目的下的动作/观察/短心理可以共段，不做“一条语义一个段落”。
- dialogue: 对话围绕当前规则、期限、价格和现实利益；唐槐实际、嘴碎但不承担搞笑科普职责。
- emotion_expression: 先让名单、数字、选择和现实结果承载压力；动作已经说明时不再自动补心理总结。
- exposition: 宗门和问果都只解释到当前行动够用的位置。问果提示短，不把未来权限树一次讲完。
- rhetoric: 仙侠感来自具体规矩、灵石、调令、修为和矿役；普通叙述仍用自然现代中文，不靠空泛古风、诗化压缩或重新组词制造仙侠感。
- system_text: 可独立成行，但必须短；系统不评价林砚聪明，不替他推荐结果。
- simulation_handling: 未来分支只展开与当前选择有价值的节点，不写成二十七天逐日流水账，也不能压成只有系统摘要。
- ending_behavior: 章末在炼气四层结果第一次确认成立处直接停，不补“从此命运改变”等总结，不多写下一拍。

## SOURCE

- language_base: Main 通用自然中文默认值。
- book_style: 主仓 `我能从未来带回一个结果/设定/文风.md`。
- genre_card: 主仓 `我能从未来带回一个结果/设定/题材正文提示卡.md`。
- author_memory: 本轮没有额外 active 文风记忆需要覆盖。
- benchmark: 无。当前章不使用外部对标。

## OVERRIDDEN_DEFAULTS
- 不使用传统“模拟日志逐条播报”作为主要正文形态。
- 不使用全员震惊、反派无理由找茬、连续三层同义解释制造爽感。
- 不为了所谓自然度在第一稿后自动全章洗文。
- 不把“修仙 / 东方仙侠”自动解释为半文半白或古雅句法。
