# EXECUTION CARD

## PROSE CORE
- chapter_function: 用一张三日后生效的矿役名单把林砚压进无常规解的处境，并完成问果第一次“未来发生 → 单选一果 → 现实落身”的核心玩法首秀。
- reader_experience: 先是低层弟子被制度一笔安排的具体窒息，再是未来死亡的惊惧，最后转成“他真的能把未来结果搬回来”的强期待。
- visible_change: 章首林砚是炼气二层末段且名字在矿役名单上；章末名单仍在，但林砚自身已经成为真实炼气四层。
- prose_pressure: 三日时限、四层硬门槛、现实资源不足。压力来自可数的规则，不靠反派现身威胁。
- explanation_limit: 籍录房和矿役制度解释到林砚能判断“顺位异常 / 四层可免 / 三日来不及正常突破”即可；问果只解释本次使用需要的四条基础规则。
- must_land: 名单与三日；顺位提前；四层免矿役；药钱/灵石现实尺子；第一次问果；未来进矿并达到四层；第二十七日死亡；多个结果只能选一个；林砚选择四层；现实四层成立。
- do_not_invent: 不新增幕后人、系统人格、隐藏反噬、未来高阶权限、额外奖励、宗门高层关注或第二章复核动作。

## SUSPENSE
- core_question: 为什么林砚会提前出现在矿役名单上，以及这张已经写好的坏结果还能不能被改掉？
- pov_knows: 林砚只知道正常顺位不该这么早轮到自己、四层可免矿役、三日常规突破几乎不可能。
- reader_knows: 与林砚同步；没有上帝视角幕后信息。
- may_reveal_this_chapter: 问果当前基础规则；原未来里林砚会进矿、修到四层、第二十七日死亡；结算只能取一个已成结果。
- forbidden_reveal: 名单幕后者、周恪寻租、问果终极来源、后续结果权限、任何司命真相。
- evidence_available: 调令上的名字与日期；正常轮转顺位；炼气四层免矿役条款；林砚当前资源与修为。
- release_order: 先把现实危机坐实，再确认常规路不够，问果才出现；未来死亡之后才进入结果选择。
- end_knowledge_state: 林砚与读者确认问果能让一个真实未来结果落回现实，但尚不知道宗门规则会不会承认这一结果。

## HOOK
- opening_function: 第一屏尽快让读者看到“林砚的名字已经在黑石矿役名单上，三日后生效”。
- ending_function: 把下一章动力从“会不会死”转换成“身体里的四层是真的，现实制度认不认”。
- approved_final_beat: 林砚确认体内已经形成炼气四层应有的完整灵力周天。
- stop_after: 这一事实第一次自然闭合后立即停止；不去考功院，不碰测灵石，不写撤名。

## EMOTION
- target_emotion: 被名单堵死退路的窒息 → 看见自己未来死亡的发冷 → 面对单选结果的集中判断 → 四层落身后的控制感第一次回来。
- carrier: 矿役调令、三日、炼气四层门槛、3枚灵石与妹妹药钱、未来死亡、唯一结果选择。
- trigger: 问果在常规路线确认无解后开启。
- visible_payoff: 不是一句“命运改变”，而是林砚的灵力运行、经脉周天和对自身境界的可验证感受已经真实变成四层。
- do_not_overexplain: 名单本身已经说明压迫时，不重复抽象感叹“命运被掌握”；四层身体结果已经成立时，不再用一段总结复述爽点。

## DIALOGUE
- relationship_action: 唐槐短场的任务是确认正常人视角里的两件事实：名单时间不对、四层可免矿役；同时让读者感到两个底层弟子都知道这事不好办。
- information_control: 唐槐只说自己按日常工作知道的规则与成本，不知道问果、不知道幕后操作，也不给解决方案。
- must_not_become_exposition: 不让唐槐用一大段对白讲完青衡宗外门体系、黑石矿历史或炼气九层全规则。
