# EXECUTION CARD

> SEMANTIC ONLY: 本卡所有策划、分析用词只传递意思，不是正文措辞、比喻或叙述声线样本。正文必须重新使用自然中文表达，不逐字段翻译本卡。

## PROSE CORE
- chapter_function: 第一章要先把林砚被提前写进矿役名单这件事坐实，再完成问果第一次“真实未来发生 → 只能带回一个已经得到的结果 → 现实真的得到这个结果”的首秀。
- reader_experience: 先让读者明白三日后去矿役这件事很危险而且正常办法来不及，再看到未来里的死亡，最后确认问果真的能改变眼前处境。
- visible_change: 章首林砚是炼气二层末段，名字已经在矿役名单上；章末名单还在，但林砚本人已经真实达到炼气四层。
- prose_pressure: 三日后调令生效；想免基础矿役必须到炼气四层；林砚现在只有二层末段，手里的灵石、贡献和人情也不足以让他按正常办法在三天内做到。压力来自这些现实事实，不靠反派出面威胁。
- explanation_limit: 籍录房和矿役制度只解释到林砚能判断“顺位不对 / 四层可免 / 三天正常突破来不及”；问果只说明本次使用必须知道的四条基础规则。
- must_land: 名单三日后生效；顺位至少提前一批；炼气四层可免基础矿役；妹妹药钱与林砚当前资源说明常规办法不够；第一次问果；未来进入黑石矿并真正修到四层；第二十七日死亡；结算有多个真实结果但只能选一个；林砚自己放弃另外两个结果并选择炼气四层；现实四层成立。
- do_not_invent: 不新增幕后人、系统人格、隐藏反噬、未来高阶权限、额外奖励、宗门高层关注或第二章复核动作。

## SUSPENSE
- core_question: 林砚为什么会提前出现在矿役名单上，以及这张已经发下来的调令还能不能避开？
- pov_knows: 林砚只知道正常顺位不该这么早轮到自己、四层可免矿役、三日内按正常修炼达到四层几乎不可能。
- reader_knows: 与林砚同步；没有上帝视角幕后信息。
- may_reveal_this_chapter: 问果当前基础规则；原未来里林砚会进矿、修到四层、第二十七日死亡；结算只能取一个已成结果。
- forbidden_reveal: 名单幕后者、周恪寻租、问果终极来源、后续结果权限、任何司命真相。
- evidence_available: 调令上的名字与日期；正常轮转顺位；炼气四层免矿役条款；林砚当前资源与修为。
- release_order: 先把现实危机写清，再确认正常办法来不及，问果才出现；未来死亡之后才进入结果选择。
- end_knowledge_state: 林砚与读者确认问果能让一个真实未来结果落回现实，但尚不知道宗门会不会承认突然出现的炼气四层。

## HOOK
- opening_function: 第一屏尽快让读者看到林砚的名字已经在黑石矿役名单上，而且三日后生效。
- ending_function: 下一章的动力从“会不会被送去矿上”转成“这个炼气四层是真的，但宗门正式流程认不认”。
- approved_final_beat: 林砚确认自己现在确实已经是炼气四层。
- stop_after: 这一事实第一次自然确认后立即停止；不去考功院，不碰测灵石，不写撤名。

## EMOTION
- target_emotion: 名单突然把退路堵住 → 看到未来里自己会死 → 必须从几个真实结果中只选一个 → 选择四层并发现现实真的变了。
- carrier: 矿役调令、三日、炼气四层要求、3枚灵石与妹妹药钱、未来死亡、唯一结果选择。
- trigger: 问果在林砚确认正常办法来不及后开启。
- visible_payoff: 选择结束后，让林砚直接从身体里的灵力运行与境界状态确认四层已经真实落到现实，不用叙述者替读者宣布“命运改变”。
- do_not_overexplain: 名单已经让危险成立时，不再反复抽象总结；四层身体结果已经成立后，不再重复解释这一结果有多重要。

## DIALOGUE
- relationship_action: 唐槐短场只负责让正常人视角确认两件事：这批本来轮不到林砚；炼气四层可以免基础矿役。两个人都明白事情不好办即可。
- information_control: 唐槐只说自己按日常工作知道的规则与成本，不知道问果、不知道幕后操作，也不给解决方案。
- must_not_become_exposition: 不让唐槐用一大段对白讲完青衡宗外门体系、黑石矿历史或炼气九层全规则。
