# 第001章对标召回｜只保留本章需要的部分

来源：《诡舍2》拆文资产。只迁移功能结构，不迁移专名、人物、桥段和具体句子。

## 本章节奏

采用“规则确定性破坏”的前半段：

1. 先给一个读者能理解的暂时规则。
2. 给出居民长期使用它的基线，让它看起来不是临时编的。
3. 出现一个很小但硬的违例。
4. 主角不直接下结论，主动验证。
5. 不同证据继续互相打架。
6. 章尾把违例坐实，但暂不解释答案。

本章只做到首次确认冲突，不进入修复。

## 本章目标情绪

“确定性被腐蚀” + “可靠型主角爽感”。

- 读者先理解电梯应该怎么安全运行。
- 再发现监控、体感、机械数据不能同时为真。
- 其他人可以恐慌、争执或依赖经验。
- 林砚的可靠来自只做当前证据允许的判断，不装全知。

情绪路径：可理解 → 微疑 → 不安 → 硬冲突 → 理性验证仍无法消除异常 → 章尾危险升级。

## 推理表达

- 行为在前，完整解释在后。
- 能通过动作制造验证条件，就先做测试。
- 不写“林砚瞬间看穿了”。
- 推理尽量落到监控、运行距离、控制板等具体可验证物件。

## 文风控制

- 第三人称限知，紧贴林砚当前观察范围。
- 常规叙事用短到中等句，清楚优先于华丽。
- 危险临界点可明显缩短段落。
- 重要反常事实可以独立落段，让读者停半拍。
- 恐怖优先来自日常设施只错了一点，而不是连续堆猎奇形容词。
- 不给每个情绪补“眼神 + 呼吸 + 心跳 + 心理解说”。
- 角色先做选择，机制只解释到足够支撑下一步行动。
