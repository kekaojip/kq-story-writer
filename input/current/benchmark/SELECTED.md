# 第002章对标选中技法

只迁移功能结构，不复制具体桥段或专名。

## 1. 证据改写模型

- 当前解释只能解释一部分事实时，不急着宣布答案。
- 主角主动增加第二、第三组可验证证据。
- 新证据出现后，旧解释被推翻或收窄。
- 新模型必须直接导出下一步行动。

## 2. 可证伪推理爽点

- 不是“主角突然看穿”。
- 先制造验证条件，再观察结果。
- 本章核心验证：机械行程 / 门磁 / 监控 / 播报四套记录同时对照。
- 第二次实验通过断开楼层显示器排除普通显示故障。

## 3. 可靠型主角

- 危险越乱，主角越不乱。
- 先把老周送走，再自己留下做活体观察样本。
- 不装全知，只做当前证据允许的正确动作。

## 4. 文风执行

- 第三人称限知，紧贴林砚当前能看到和合理推测的信息。
- 行为在前，完整解释在后。
- 异常落在具体物件：门磁、显示器、监控、播报、机械位移。
- 重要反常事实可以独立落段，但不要每个情节点都强行短段。
- 不用大段机制说明替代现场验证。
