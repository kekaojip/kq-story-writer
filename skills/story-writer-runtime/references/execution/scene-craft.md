# Scene Craft Execution Slice

> Writer 执行切片。来源于主工作流 `style-craft.md` 的正文落地能力。只负责已经批准场景的镜头、视角、动作、环境交互与叙述可读性；不拥有选题、剧情设计、人物设计、爽点设计或新增事件权限。

## 权限边界

- 只处理“已经决定发生什么”之后的正文呈现。
- 不新增事件、人物、设定、伏笔、反转、奖励、冲突或长期后果。
- `01_OUTLINE.md`、`02_CURRENT_STATE.md`、`04_BOUNDARIES.md` 与 `EXECUTION_CARD.md` 优先于本文件。
- Human Writing L2 优先于本文件中的任何固定节奏倾向：不使用句长、段长、事件数或对话长度配额。

## 1. 情绪落地

情绪没有固定译法。按当前场景选择最有信息量的一种：

1. 上下文已经让情绪成立：不再补解释或微动作尾巴。
2. 情绪改变下一步：写选择、台词、策略、关系动作或实际后果。
3. 场内事物能承载变化：优先写当前正在处理的物件、任务、门、消息、工具、食物等发生的实际变化。
4. 身体确实受影响：只有疼痛、失衡、动作失败、伤势或其他可见后果值得展开。
5. 直写最准确时可以直接写，不为“高级”绕成表演。

同一情绪节点不要叠成“动作 + 身体 + 比喻 + 心理解说”的四重注释。

## 2. 镜头与视角

- 默认服从任务指定 POV。有限视角下，只写该视角人物当前可获得的信息。
- 不用“此时他还不知道”“如果她知道真相”之类越权旁白提前泄露未来或隐藏真相。
- 已批准的视角切换可以执行，但必须有清楚的场景或段落边界。
- 环境描写优先与人物当前行动、风险、感知或题材机制发生交互；纯装饰环境能删则删。

## 3. 场景连续性

正文不是把细纲节点逐条翻译。把同一场戏内属于同一因果口气的动作、对白、观察与心理自然织在一起。

优先顺序：

`当前刺激 → 人物接触/判断 → 行动或对白 → 世界反馈/结果 → 下一拍`

这只是因果方向，不是固定句式模板。已经由动作或结果表达清楚的意义，不再追加总结。

## 4. 具体感

- 动词优先承担画面。
- 数字、物件、空间位置、声音、触感只有在当前场景已有依据且能增加信息时使用。
- 不临时搬入无来源物件只为表现情绪。
- 感官不是配额；最有用的一个感官已经够，就不要把五感全部补齐。

## 5. 段落与手机阅读

- 按动作、信息变化、说话人变化、注意力转移自然分段。
- 连续对白可以短段，但不要把所有叙述拆成一行一句。
- 长段只在同一叙述动作确实需要持续展开时保留；不要为了“手机阅读”把完整动作链切碎。

## 6. 对话承接

- 对话以人物当前目的和关系动作为核心，不要求每句都完整说明全部立场。
- 标签低频即可，普通“说”可以自然使用。
- 动作承接必须有当前功能，不用“目光一闪、指尖一顿”当万能标签。
- 高压场景里不自动插入玩笑、口头梗或科普长段，除非人物和当前任务明确支持。

## 7. Writer 自检

只问：

- 这一段是在发生故事，还是在执行提纲？
- 视角人物是否知道了不该知道的东西？
- 情绪是不是已经由上下文/动作/结果成立，却又被解释了一遍？
- 环境、动作、物件有没有实际功能？
- 有无为了“写得像小说”而额外制造表演性细节？

发现问题只做局部修复，不重设计故事。
