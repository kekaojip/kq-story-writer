# Reversal Execution Slice

> Writer 执行切片。只负责把主模型已经批准的反转线索、误导、揭示和认知变化写成正文，不负责设计反转本体。

## 权威输入

反转相关事实只从以下来源取得：

1. `04_BOUNDARIES.md`：禁止提前释放的真相。
2. `01_OUTLINE.md`：本章批准的反转动作与揭示时点。
3. `02_CURRENT_STATE.md`：人物当前认知。
4. `benchmark/EXECUTION_CARD.md` 的 `REVERSAL` 模块（若存在）。

没有上游明确提供的表层认知、真实事实、线索、揭示结果，不得自行补造。

## 1. 铺垫怎么写

如果本章只负责铺垫：

- 把批准线索自然放进人物当前会接触到的动作、物件、对白或结果里；
- 线索出现时不要旁白解释“这其实暗示了什么”；
- 线索的显眼程度服从 `EXECUTION_CARD`；
- 不为了让读者记住而重复三遍同一异常。

## 2. 误导怎么写

误导必须建立在真实可见信息或人物有限认知上。

可以：

- 让人物基于当前证据形成错误判断；
- 只呈现事实的一部分；
- 把注意力自然放在另一个更紧迫的问题上。

不可以：

- 叙述者直接说假话；
- 隐去 POV 明明已经看见且会立刻理解的关键信息；
- 为误导新增不存在的证据；
- 让角色突然变笨。

## 3. 揭示怎么写

如果本章批准揭示：

- 优先让新证据、行为、选择或现实结果直接打破旧认知；
- 能用一个场景完成，就不要让角色站着长篇解释真相；
- 揭示后只写当前人物真实能处理到的认知变化，不自动把全部历史意义总结完；
- 如果上游只批准“发现矛盾”，不要擅自推进到“确认全部真相”。

## 4. 反转后的余波

反转完成不等于所有人都立刻理解一致。

按输入分别处理：

- 谁已经知道；
- 谁仍不知道；
- 谁只知道部分；
- 谁仍坚持旧解释；
- 当前关系/行动是否已经因此变化。

不把认知同步当默认结果。

## 5. 不同反转类型的执行重点

### 身份 / 信息反转
重点写可验证的新证据和现实后果，少用自白式说明。

### 动机反转
重点让角色在关键选择里的行为暴露真实倾向。只有上游批准时才明确解释动机。

### 视角 / 认知反转
保持此前事实仍然成立，只改变读者和人物对这些事实的解释。不要回头篡改已经发生的事实。

### 时间线反转
严格服从上游时间事实；Writer 不自行调换时间或补记录。

## 6. 与 Human Writing L2 的关系

- 反转揭示后不自动写“他终于明白一切”。
- 新事实可以只改变当前动作，不必立刻完成整套人生反思。
- 对白可以只处理当前关系动作，不要求角色把真相说明书说完。
- 不为了“震撼”连续堆金句、短句、感叹号或旁观者齐刷刷反应。

## 7. 自检

- 真相有没有提前？
- 是否新增了线索/证据/动机？
- 角色知道的内容是否超出当前状态？
- 揭示是否从“发现异常”擅自升级到“全部确认”？
- 揭示后有没有解释过头？
- 本章结束后各角色知识状态是否与上游一致？
