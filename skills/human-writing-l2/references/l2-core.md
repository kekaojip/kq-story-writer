# L2 Core｜活人感正文核心

## 0. Completion Variance｜完成度波动

模型最容易暴露的，不是“不流畅”，而是**长期保持同一种完成度**。

高风险状态：

```text
每句话都完整
每个情绪都解释
每个问题都处理
每个转折都说明
每个段落都收口
每次发现都立即得出正确结论
```

自然正文允许不同局部停在不同完成位置：

- 有的事实直接说完；
- 有的只留下动作结果；
- 有的情绪由对白承担；
- 有的情绪可以直接点明；
- 有的问题立刻解决；
- 有的问题只处理到够行动；
- 有的意义晚一点才回来；
- 有的局部根本不需要专门结算。

```text
LOCAL_COMPLETENESS: VARIABLE
UNIFORM_COMPLETENESS: UNDESIRED
```

完成度波动不是“故意写残”。不要按配额制造：

- 半句话；
- 犹豫；
- 省略；
- 短句；
- 普通句；
- 答非所问。

这些只有在人物、关系、现场与当前注意力自然支持时才出现。

> **不要模拟人类的瑕疵，而是停止模型把所有东西加工到同样完整。**

## 1. 不连续制造漂亮闭合

模型很容易把局部段落加工成：

```text
铺垫
→ 短句
→ 解释
→ 总结
→ 小落点
```

偶尔出现没有问题，连续复制就会产生强烈施工感。

允许：

- 普通陈述直接过去；
- 一段没有专门总结；
- 强句周围存在普通句；
- 一件事还没完全收束，下一件事已经进来。

禁止把每段都修成“完成品”。

## 2. 新信息不要一次推演到底

新规则、新能力、新异常、新身份、新数字出现时，人物只处理眼前够用的部分。

高风险模型链：

```text
发现事实
→ 验证事实
→ 解释用途
→ 分析战略价值
→ 推演长期影响
→ 制定未来计划
```

除非当前场景确实要求，否则在“足以决定下一步”的位置停止。

```text
COGNITIVE_STOP = ENOUGH_FOR_NEXT_ACTION
```

## 3. 认知颗粒允许不统一

自然叙述不会把每条信息都处理成同样大小。

允许：

- 有的信息一句讲完；
- 有的事情多想几句；
- 有的先误解；
- 有的暂时不解释；
- 有的后来再次进入注意力；
- 有的最终也没有专门总结。

禁止为了“简洁”把所有认知压成同一种短判断，也禁止为了“真人感”统一拖慢。

## 4. 段落按叙述块形成

段落形成看的是叙述是否仍是一口气，而不是又出现了一个新语义标签。

同一人物 + 同一注意对象 + 同一时间地点 + 同一局部目的下：

- 动作；
- 观察；
- 心理；
- 对白后的自身动作；
- 补充说明；
- 短因果；

可以自然共居。

优先换段条件：

- 说话人切换；
- 注意中心明显变化；
- 时间 / 地点变化；
- 动作阶段变化；
- 真正的情绪或因果落点；
- 一口连续叙述确实结束。

```text
NEW_INFORMATION != AUTOMATIC_PARAGRAPH_BREAK
```

## 5. 允许普通和局部毛边

正文不是展厅。

允许：

- 普通连接词；
- 常见动词；
- 重复一个普通词；
- 一句稍长但顺的句子；
- 一段稍短但不承担重音；
- 关系型重复；
- 一点没有结构价值但属于人物当下的废话；
- 局部不均匀注意力。

不要为了“人味”主动添加：

- 错别字；
- 病句；
- 无来源口语；
- 随机误会；
- 随机失败；
- 降智；
- 奇怪动作。

## 6. 不把输入当覆盖清单

批准的剧情输入负责限定故事事实，不负责规定正文每一项必须露脸、每一项写几段。

```text
INPUT ORDER != PROSE ORDER
INPUT COMPLETENESS != PROSE COVERAGE RATE
```

可以：

- 两个节点自然合并；
- 一个节点一句带过；
- 从结果进入；
- 相邻事件重叠发生；
- 用对白或动作替代解释；
- 不写不承重的观察。

只要承重事件、结果、硬事实和边界没有被改坏。

## 7. 不追加开章仪式

如果批准输入从正在发生的生活、工作、赶路、课堂、吃饭、守候开始，就直接从那里开始。

不要为了“像第一章”自动补：

- 苏醒扫描；
- 身体检查；
- 排除梦境；
- 重复确认身份；
- 环境启动镜头；
- 主题式开篇。

除非这些本来就是批准事件。

## 8. 不追加章末盖章

当最后事件、对白、动作、结果或 stop 已成立时，到那里或最自然的即时反应即可停。

不要自动追加：

- “到这一刻他才真正意识到……”；
- 本章核心名词复盘；
- 长期价值总结；
- 未来路线；
- 专门设计的漂亮 punchline；
- 未批准的下一章钩子。

> **开头不负责宣布故事开始，结尾不负责证明这一章完整。**
