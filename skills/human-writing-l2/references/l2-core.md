# L2 Core｜活人感正文核心

## Natural Chinese Floor｜自然中文底线

Human Writing L2 的所有“完成度波动、少解释、少闭合、允许毛边”规则，都建立在一个更基础的前提上：**句子本身先是自然中文。**

```text
SEMANTICALLY_VALID != NATURAL_CHINESE
NATURAL_CHINESE_FLOOR: REQUIRED
```

默认适用于所有小说题材：

- 旁白与贴角色叙述优先使用自然、现代、第一次就能顺着读懂的中文；
- 常见中文搭配优先于模型临时生造的词组、诗化压缩、翻译式组合和为了“高级感”重新组装的表达；
- 一个表达即使能解释出意思，只要正常读者需要先在脑中改写成另一句中文才能顺畅理解，就视为自然度缺陷；
- 题材专名、世界观名词、身份称谓可以具有时代或类型色彩，但不能自动把普通动作、判断、心理和叙述句做旧、古文化、公文化或论文式抽象化；
- 除非当前任务、本书文风或角色身份明确要求古典 / 文言 / 特殊实验语体，否则自然现代汉语是基础层，题材风格只能叠加在其上；
- 普通、顺口、清楚优先于精炼、漂亮、金句化；如果“更漂亮”会让搭配变陌生，退回普通说法；
- 允许自然中文需要的“的、了、就、已经、但是、后来、一下、这个、那个”等连接、指代和语气，不为了所谓精炼把句子脱水成提纲；
- 不把策划、审稿、产品、项目管理或论文层的抽象词汇继承成叙述声线。输入中的分析词只传递语义，正文需要重新成文；
- 不把“自然白话”误解成聊天腔，不机械添加网络黑话、俚语、口头禅、脏话、语气词或对白比例。

写一句话时，优先顺序是：

```text
意思准确
→ 中文搭配自然
→ 人物 / 视角合适
→ 节奏与文风
→ 修辞与漂亮程度
```

后面的层级不能牺牲前面的层级。

高风险自检：

- 这个动词通常会和这个宾语这样搭吗？
- 这个形容 / 比喻是在帮助理解，还是只是在让句子显得“像小说”？
- 去掉题材标签后，一个正常中文写作者还会这样组词吗？
- 朗读时是否像论文、策划案、翻译句、半文半白或刻意压缩的金句？

命中时优先回到常用表达，不需要另造一条“更像人”的漂亮句。

## 0. Completion Variance｜完成度波动

模型最容易暴露的，不是“不流畅”，而是**长期保持同一种完成度**。

高风险状态：

```text
每句话都完整
每个情绪都解释
每个问题都处理
每个转折都说明
每个段落都收口
每次发现都立即得出正确结论
```

自然正文允许不同局部停在不同完成位置：

- 有的事实直接说完；
- 有的只留下动作结果；
- 有的情绪由对白承担；
- 有的情绪可以直接点明；
- 有的问题立刻解决；
- 有的问题只处理到够行动；
- 有的意义晚一点才回来；
- 有的局部根本不需要专门结算。

```text
LOCAL_COMPLETENESS: VARIABLE
UNIFORM_COMPLETENESS: UNDESIRED
```

完成度波动不是“故意写残”。不要按配额制造：

- 半句话；
- 犹豫；
- 省略；
- 短句；
- 普通句；
- 答非所问。

这些只有在人物、关系、现场与当前注意力自然支持时才出现。

> **不要模拟人类的瑕疵，而是停止模型把所有东西加工到同样完整。**

## 1. 不连续制造漂亮闭合

模型很容易把局部段落加工成：

```text
铺垫
→ 短句
→ 解释
→ 总结
→ 小落点
```

偶尔出现没有问题，连续复制就会产生强烈施工感。

允许：

- 普通陈述直接过去；
- 一段没有专门总结；
- 强句周围存在普通句；
- 一件事还没完全收束，下一件事已经进来。

禁止把每段都修成“完成品”。

## 2. 新信息不要一次推演到底

新规则、新能力、新异常、新身份、新数字出现时，人物只处理眼前够用的部分。

高风险模型链：

```text
发现事实
→ 验证事实
→ 解释用途
→ 分析战略价值
→ 推演长期影响
→ 制定未来计划
```

除非当前场景确实要求，否则在“足以决定下一步”的位置停止。

```text
COGNITIVE_STOP = ENOUGH_FOR_NEXT_ACTION
```

## 3. 认知颗粒允许不统一

自然叙述不会把每条信息都处理成同样大小。

允许：

- 有的信息一句讲完；
- 有的事情多想几句；
- 有的先误解；
- 有的暂时不解释；
- 有的后来再次进入注意力；
- 有的最终也没有专门总结。

禁止为了“简洁”把所有认知压成同一种短判断，也禁止为了“真人感”统一拖慢。

## 4. 段落按叙述块形成

段落形成看的是叙述是否仍是一口气，而不是又出现了一个新语义标签。

同一人物 + 同一注意对象 + 同一时间地点 + 同一局部目的下：

- 动作；
- 观察；
- 心理；
- 对白后的自身动作；
- 补充说明；
- 短因果；

可以自然共居。

优先换段条件：

- 说话人切换；
- 注意中心明显变化；
- 时间 / 地点变化；
- 动作阶段变化；
- 真正的情绪或因果落点；
- 一口连续叙述确实结束。

```text
NEW_INFORMATION != AUTOMATIC_PARAGRAPH_BREAK
```

## 5. 允许普通和局部毛边

正文不是展厅。

允许：

- 普通连接词；
- 常见动词；
- 重复一个普通词；
- 一句稍长但顺的句子；
- 一段稍短但不承担重音；
- 关系型重复；
- 一点没有结构价值但属于人物当下的废话；
- 局部不均匀注意力。

不要为了“人味”主动添加：

- 错别字；
- 病句；
- 无来源口语；
- 随机误会；
- 随机失败；
- 降智；
- 奇怪动作。

## 6. 不把输入当覆盖清单

批准的剧情输入负责限定故事事实，不负责规定正文每一项必须露脸、每一项写几段。

```text
INPUT ORDER != PROSE ORDER
INPUT COMPLETENESS != PROSE COVERAGE RATE
```

可以：

- 两个节点自然合并；
- 一个节点一句带过；
- 从结果进入；
- 相邻事件重叠发生；
- 用对白或动作替代解释；
- 不写不承重的观察。

只要承重事件、结果、硬事实和边界没有被改坏。

## 7. 不追加开章仪式

如果批准输入从正在发生的生活、工作、赶路、课堂、吃饭、守候开始，就直接从那里开始。

不要为了“像第一章”自动补：

- 苏醒扫描；
- 身体检查；
- 排除梦境；
- 重复确认身份；
- 环境启动镜头；
- 主题式开篇。

除非这些本来就是批准事件。

## 8. 不追加章末盖章

当最后事件、对白、动作、结果或 stop 已成立时，到那里或最自然的即时反应即可停。

不要自动追加：

- “到这一刻他才真正意识到……”；
- 本章核心名词复盘；
- 长期价值总结；
- 未来路线；
- 专门设计的漂亮 punchline；
- 未批准的下一章钩子。

> **开头不负责宣布故事开始，结尾不负责证明这一章完整。**
