# Positive Writing｜第一稿正向成文发动机

> 只用于 FIRST_DRAFT。不是审稿表，不列 AI 症状，不要求逐项自检。

## 1. 输入不是待翻译文本

把已批准的当前章故事输入当成“作者知道这章大致会发生什么”，不要按输入句序逐条展开。

写前只抓眼前这一小段真正的叙事重心。

```text
INPUT ORDER != PROSE ORDER
INPUT COMPLETENESS != PROSE COVERAGE
```

未轮到的事先不写；只负责保持硬事实不写错，不负责让所有设定露脸。

## 2. 第一次碰到异常，只给够眼前继续的反应

人物第一次遇到异常、陌生身份、系统、规则或关系变化时，通常只需要：

```text
异常进入感知
+ 一个最自然的直接反应
```

不要自动启动：

```text
再看一次
→ 再摸一下
→ 排除错觉
→ 检查身体
→ 确认身份
→ 总结意义
```

如果一个身份事实一句直接讲清最自然，就直接讲。

## 3. 一个主证据够行动，就停止证明

系统 / 能力 / 规则第一次出现时，如果一个自然样本已经足够让人物继续行动，就不要把同功能对象逐个测试。

一次现实回应足够人物先往下走时，就往下走。

剩余信息可以以后再出现，也可以永远不专门演示。

## 4. 一条信息通常只加工一两层

不要给每条信息同时配齐：

```text
画面
+ 动作反应
+ 心理解释
+ 意义总结
+ 金句
```

多数时候一两层就够：

- 事件 + 反应；
- 事件 + 一句直接背景；
- 对白 + 一个小动作；
- 直接讲完，然后继续生活。

人物不是实时分析器。

## 4.5 Meaning Already Carried｜意义已经被承载

写下一层解释之前，先看当前这一拍是不是已经完成了自己的工作。

```text
动作已经表达态度？
→ 不自动补心理解释

对白已经完成当前关系动作？
→ 不自动补情绪说明

现实结果已经让读者看懂？
→ 不自动补结论

人物已经有足够理由继续行动？
→ 停止证明
```

这不是“动作永远优于心理”或“对白永远要短”。

如果心理、解释或直接情绪命名本身承担新信息、人物声音或当前决策，它们可以保留。

判断标准只有一个：

> **后一层是在继续故事，还是只在把前一层已经完成的意义再说一遍？**

如果只是重复完成，优先让正文继续走。

## 5. 允许局部不周全

允许：

- 有的过程略过；
- 有的念头没想完就先行动；
- 一个问题先放着；
- 人物只抓当前最关心的那一点；
- 当前反应不包含作者想表达的全部意义。

不要把每件事都处理到相同完整度。

## 6. 复合叙述

同一人物、同一注意对象、同一时间地点、同一局部目的下的相关事实、动作、补充、态度和短因果可以共居。

不要写成隐形列表：

```text
一个事实。
一个判断。
一个补充。
一个总结。
```

先讲一整坨自然意思，再决定需要几句话、几个段落。

## 7. 换段要有真实理由

可以换段：

- 说话人切换；
- 注意中心变化；
- 时间 / 地点变化；
- 真实重音；
- 危险结果；
- 笑点；
- 一口连续叙述结束。

普通新信息不是换段理由。

单句段只留给确实需要停一下的地方，不作为移动端默认格式。

## 8. 允许直接讲，篇幅不均匀

前史、身份、环境、生活背景，如果一句或一段直接讲最自然，就直接讲，不为了“表现”拍成六个镜头。

有的东西一句结束，有的关系多待半页。

正文注意力不需要严格按剧情节点平均分配。

## 9. 普通生活可以暂时与主卖点并行

生活、钱、吃饭、工作、熟人、旧关系，如果本来属于当前人物和场景，可以短暂存在，不必每次都立刻接回核心设定或主线意义。

但不能为了“人味”新造一段无关支线。

## 10. 开始和停止只是切口

第一段不是开章仪式。

章尾边界是天花板，不是“必须写到某个漂亮镜头才算完”的靶心。

只要没越线，正文可以在自然事件、对白、动作或余波处切断。

## 11. Writer 只做三件事

```text
1. 把批准的当前章故事写成活的连续故事；
2. 不写错硬事实与人物知识；
3. 不越过停止边界。
```

不负责证明自己遵守了多少防 AI 规则。
