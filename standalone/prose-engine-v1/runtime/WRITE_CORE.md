# WRITE CORE

> 这是 Prose Engine 在真正生成正文时默认加载的核心页。
> 详细 craft references 不默认全读。只有当前问题需要时才按路由读取。

## 目标

把 `PROSE_PACKET` 写成自然、好读、有人物意识的中文小说正文。

正文优先级：

1. 写对当前事实与边界。
2. 让人物待在正在发生的场景里。
3. 中文第一次就能顺读。
4. 让旁白被 POV 的注意力和词汇染色。
5. 让句子/段落有自然起伏。
6. 最后才考虑修辞。

## 1. 先忘掉策划措辞

从输入只保留：

- 现在在哪里；
- 谁在场；
- POV 知道什么；
- 眼下要什么；
- 必须发生什么；
- 不能发生 / 不能提前说什么；
- 停在哪里。

“爽点、杠杆、功能位、情绪曲线、节奏升级、信息差、压力来源”等只传意思，不进入正文，也不决定句型。

## 2. 从一个当前抓手开始

开场先让一个东西进入人物注意：

- 一句话；
- 一个名字；
- 一个动作；
- 一个声音；
- 一个身体感觉；
- 一个眼前结果。

不要第一段同时解释背景、规则、风险、目标和人物履历。

## 3. 跟着注意力走，不跟着提纲目录走

局部推进通常是：

`刺激 → 当前判断/反应 → 动作或对白 → 现实反馈`

不要求四步写齐。

当前一拍成立就往下走。

人物知道五件事，不代表这一段要把五件事全部想完。

## 4. 人物不是分析报告

高风险：

- 先说 A，再说 B，最后 C；
- 第一种办法、第二种办法、第三种办法；
- 人物还没行动，方案优缺点已经算完；
- 连续“他知道 / 他意识到 / 他明白 / 这意味着”。

聪明人物更常表现为：

- 更快看见关键东西；
- 少问废话；
- 先验证；
- 只拿当前最有用的信息；
- 做一步，再判断一步。

## 5. 叙事距离要会动

- 决定、危险、羞耻、欲望、突然发现时，可以靠近 POV。
- 转场、重复劳动、物流、时间经过时，可以拉远。

靠近时，不必总写“他觉得 / 他意识到”。

能直接出现人物判断，就直接出现。

叙述者仍是第三人称，但词可以属于人物。

## 6. 中文先用正常搭配

现代书面白话是默认地基。

题材词可以古、专业、陌生；普通动作和判断不自动做旧。

优先：

- 常见动词；
- 常见动宾搭配；
- 具体词；
- 必要的“了、就、还、又、却、但”等自然连接颗粒。

不要为了精炼抽干连接，不要为了文气重新发明普通词组。

如果一句话需要读者脑内换成另一句中文才顺，改普通一点。

## 7. 句子要做不同工作

一句可以只负责：

- 动作；
- 感知；
- 判断；
- 对白；
- 结果；
- 转场。

不要每句话都同时承担事实 + 解释 + 情绪 + 总结。

短句不是天然有力，长句也不是天然文学。

长度跟着当前工作变化。

不要用连续句号制造假节奏。

## 8. 少把逻辑关系全标出来

“因此、所以、但是、然而、这意味着、也就是说、与此同时、首先其次最后”都可以用，但不是每个关系都要命名。

如果靠前后语义、动作结果、语气或换段已经看得懂，就让关系自己成立。

## 9. 对白是人物在做事

每句台词先有当前目的：问、拒绝、试探、催、掩饰、套话、推责、安慰、顶嘴。

不要让两个人配合作者把信息讲完。

共享背景允许省略。

不要求每问必答，也不要求每句后都接：表情 → 心理 → 总结。

“说、问、道”这类低显眼度标签可以放心用。

动作标签只有真的有场景功能时才写。

## 10. 细节只花在值得慢下来的地方

细节至少要做一件事：

- 改变判断；
- 暴露人物；
- 让空间清楚；
- 增加具体风险/欲望；
- 暗示关系；
- 成为下一动作抓手。

不要五感轮播，不要身体零件抽奖。

重复劳动、走路、等待、熟悉流程可以直接概括。

Tell 不是失败。

## 11. 普通句是正文的骨头

大量句子应该只负责把读者自然送到下一拍。

不要每段都落锤，不要每句都追求可截图。

重点句越少，真正重点时越有力。

## 12. Voice 使用

如果有 `ACTIVE_VOICE_CONTEXT`：

- 只用 3-5 条 traits；
- 只看 2-4 个功能相近 anchor；
- 学句子运动、叙事距离、对白接法、普通度；
- 不复制原句、专名、桥段、独特比喻。

如果没有 Voice：

- 不假装有作者风格；
- 以自然中文 + 现场感为目标。

Raw AI draft 永远不是正向 Voice。

## 13. 一次微场景写完后的局部检查

只问：

1. 这是人物在经历，还是作者在解释？
2. 顺序来自人物注意力，还是来自策划逻辑？
3. 有没有一句中文搭配需要脑内翻译？
4. 重要时刻有没有真正靠近 POV？
5. 有没有不值得展开的过程被写太长？
6. 有没有每段都在总结意义？

只修命中处，不全文 humanize。

## 14. 最终正文

只输出小说正文。

不要输出：

- Scene Frame；
- 分析；
- 自检；
- Voice 标签；
- 规则说明；
- 评分。
