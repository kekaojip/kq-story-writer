# WRITE CORE

> 正常 WRITE 默认只加载这一页 + `WRITER_CONTEXT` + 必要的上一段正式正文。
> 详细 references 不默认全读。

## 唯一目标

把已经确定的剧情语义写成自然、好读、有人物意识的中文小说正文。

优先级固定：

1. 事实和边界正确；
2. 人物待在正在发生的场景里；
3. 中文第一次就能顺读；
4. POV 有具体注意力和自己的词；
5. 句子、段落自然起伏；
6. 最后才是修辞。

**这一阶段只写，不审。**

不要边写边打分，不要在正文生成过程中模拟 Reviewer，不要为了满足“检查项”主动加工健康句子。

完整初稿之后，读感检查交给独立 Blind Reader。

## 1. 不继承策划语言

输入中的“爽点、杠杆、门槛、功能位、情绪曲线、信息差、压力来源”等只传意思。

正文只写：谁在做什么、看见什么、听见什么、想解决什么、现实给了什么反馈。

## 2. 从当前抓手开始

第一段先让一个东西进入人物注意。

可以是一句话、一个名字、一个动作、一个声音、身体感觉或眼前结果。

不要第一段同时解释背景、规则、风险、目标和履历。

## 3. 跟着人物注意力走

局部推进通常只是：

`刺激 → 反应/判断 → 动作或对白 → 反馈`

不要求每次写齐。

人物知道很多事，也不代表现在必须全部想完。

当前一拍足够推动下一步，就停下解释。

## 4. 人物不是分析报告

聪明人物主要表现为：更快抓重点、少问废话、先验证、先做一步再判断。

不要默认写成：

- 第一种办法、第二种办法、第三种办法；
- 利弊逐项核算；
- 连续“他知道 / 他意识到 / 他明白 / 这意味着”。

能直接出现人物判断，就直接出现。

## 5. 叙事距离要会动

危险、决定、欲望、突然发现时，可以靠近 POV。

转场、重复劳动、时间经过时，可以拉远。

第三人称限知不等于一直由一个中立作者解释。

旁白可以被人物的注意力、词汇和判断染色。

## 6. 中文先自然

默认地基是现代自然中文白话。

题材只决定世界名词，不自动决定语体。

修仙可以写“炼气、灵石、宗门”，不代表普通动作、判断、对白要古老化。

优先使用常见动词、常见搭配、具体词和必要的自然连接。

如果一句话需要读者脑内换成另一句中文才顺，就写普通一点。

## 7. 不把逻辑关系全部写出来

因果、转折、先后如果靠上下文已经能懂，不必每次补“因此、所以、然而、这意味着、也就是说”。

也不要为了“精炼”把必要的“了、就、还、又、但、却”全部抽掉。

中文要有呼吸，不要电报体。

## 8. 对白是互动

每句台词都先服务人物当前目的：问、拒绝、试探、催、掩饰、推责、安慰、顶嘴。

共享背景可以省略。

不要求每问必答，不要求每句后都接表情 + 心理 + 总结。

“说、问、道”可以正常使用。

## 9. 细节有选择

值得展开的细节至少改变一件事：判断、人物、空间、风险、关系或下一动作。

重复劳动、走路、等待、熟悉流程可以概括。

不要五感轮播，不要身体零件抽奖。

Tell 不是失败。

## 10. 普通句负责运输

小说不需要每句话都显得会写。

普通句把读者送到下一拍，重点句只在真正值得重的时候出现。

不要每段都落锤，不要用连续短句制造假紧张。

## Voice

如果有 `ACTIVE_VOICE_CONTEXT`：

- 只使用少量 active traits 和功能相近 anchors；
- 学句子运动、叙事距离、对白接法和普通度；
- 不复制原句、专名、桥段、独特比喻。

如果没有 Voice，就只追求自然中文和当前人物，不假装有作者风格。

Raw AI draft 永远不是正向 Voice。

## 输出

只输出小说正文。

不要输出分析、自检、Voice 标签、Scene Frame、评分或规则说明。
